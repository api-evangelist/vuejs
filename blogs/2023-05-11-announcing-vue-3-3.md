Today we're excited to announce the release of Vue 3.3 "Rurouni Kenshin"! This release is focused on developer experience improvements - in particular, SFC usage with TypeScript. Together with the 1.6 release of Vue Language Tools (previously known as Volar), we have resolved many long-standing pain points when using Vue with TypeScript.
